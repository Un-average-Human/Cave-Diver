### How this project came to be.
You know, this is actually a pretty funny story. Me and my friend were participating in the Auckland Campfire Hackathon when the theme was revealed to be "under the surface". I wanted to make something related to caves while my friend wanted something more unique (he's too sophisticated). In the end I pitched
an idea for a Saddam Hussein simulator as a joke, which ended up sticking. We tweaked it a little so it wasn't a complete joke and this was the result!

### Info about it
I made this spooky game in Godot, since I've been using it since uh, 2024 I think. Godot was my only choice back then since my school laptop was horrible and the school computers coudn't even run microsoft apps properly. Since it was free and light it was my only option. I had never made a public project until this one, especially since I mostly make systems so it makes it easier to integrate them to other projects and they don't burn me out. For the models I used Blender of course, since it is free and I have also gathered the skills to use it. The game basically revolves around a single mechanics, that being the crawl. You need to crawl through tight spaces and go deeper in the cave to investigate it. I had to make it simple for the game jam after all lol. I unfortunately can't provide any extra images since they would just spoil the game so go play it and get a lil spooked!

### General stuff
Controls are in the itch.io game description. Fullscreen the game when playing and make sure to pay attention to the audio since it is extremely important for the atmosphere.
